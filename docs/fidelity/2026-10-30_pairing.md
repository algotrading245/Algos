## Why Tokyo traded 0.68x the tester's size: tester warm-up, not execution
- Tokyo sizing includes a loss-run factor: InpLossMult 0.67 for each loss in a row, divided by InpLossNorm 0.80.
- **Demo:** its previous Tokyo trade, on 10-23, sold 0.24 at 156.420 and was stopped at 156.896. That is a run of 1 loss, so the factor is 0.84.
- **Tester:** it starts on 10-28 with no history, so its run is 0 and its factor is 1.25.
- 0.84 / 1.25 = 0.67, which matches the measured ratio. The model weight (0.87 vs 0.86) and the stop distance (48.5 pips on both) match.
- **For later pairings:** start the tester run at least one Tokyo trade before the window, so that history-based sizing matches.
