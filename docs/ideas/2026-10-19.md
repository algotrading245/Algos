## Step 4: China release calendar (data for `china_release_aud`)

Output: `marketdata/china_calendar_nbs.csv` (written locally; not committed this run, which commits only this file and
the decisions log). Times are Beijing (BJT) and UTC; the UTC column is BJT minus 8 hours.

- **Series:** GDP ("National Economic Performance" / "Press Conference on Economic Situation"), CPI (monthly, 09:30
  BJT), and ACTIVITY ("Industrial Production Operation", monthly, 10:00 BJT). **Trade (customs) is not in this file.**
- **Coverage:** 2015-01 to 2025-09-30 (cut before the holdout START of 2025-10-13; the source 2025 calendar also lists
  Oct-Dec 2025 and those rows were not written). Row counts: GDP 97, CPI 129, ACTIVITY 117 (343 rows).
- **Source:** the NBS English "Regular Press Release Calendar" pages for each year, read through `WebFetch`, which
  returns a summary and not the raw table. Each row should be checked against the page before a test uses it.
- **Gaps:**
  - 2010-2014 not fetched. The search did not return those calendar pages, and I did not guess URLs.
  - Customs trade calendar not found.
  - 2022-10-24: GDP listed as "Online" with no time. Its ACTIVITY row shows 09:30 in the source, not 10:00.
  - 2024-07-15: GDP listed as "Online" with no time.
  - 2018-01-18: both rows printed as 15:00, unlike every other month. Likely a typo in the source; check.
  - 2022-09-16 GDP printed as 09:30 (the other months are 10:00); flagged.
  - 2015 ACTIVITY times are matched to dates by order because the page does not print them against each date, and
    some are 13:30. Flagged in the file. 2016 ACTIVITY has the same 13:30 pattern for some months; those rows are
    read as printed.
  - 2020 GDP has only the four quarterly rows.
  - The 2025 calendar is the pre-publication schedule from December 2024, not confirmed release history.
- **Use for `china_release_aud`:** the file is enough to test the 10:00 and 09:30 BJT windows (02:00 and 01:30 UTC),
  and it gives 343 GDP, CPI and activity timestamps for 2015-2025.09. It does not include trade, and it does not cover
  2010-2014. The paper's own sample is 2000-2016, so a test on this file covers 2015-2025 only. Step 5 should state
  that the sample starts in 2015 unless the older calendars are found.
